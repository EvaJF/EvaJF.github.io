# Eva Feillet website redesign

This package contains the revised multi-page website. It uses a standalone `site.css` file and the portrait in `images/pp1.png`.

## Pages
- `index.html` — research-oriented homepage
- `publications.html` — complete publication list
- `talks-service.html` — invited talks, presentations, tutorials, and service
- `events.html` — conferences, workshops, and summer schools
- `teaching.html` — teaching activities
- `opportunities.html` — student and PhD topics
- `cv.html` — web CV

## Link audit
The external links in the supplied original HTML were audited against these pages. All 68 unique external URLs from the source are represented, including publication resources, former supervisors and collaborators, laboratories and teams, research programmes, teaching colleagues, event pages, and academic profiles.
